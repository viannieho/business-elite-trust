# 業務菁英｜客戶信任競爭力實戰課

此資料夾可直接部署至 GitHub Pages。圖片位於 `assets/`，入口為 `index.html`。

## 部署
1. 在 GitHub 建立公開 repository。
2. 將 `index.html`、`assets/` 資料夾上傳至 repository 根目錄。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 網站網址通常為 `https://使用者名稱.github.io/儲存庫名稱/`。

**注意：** Google 表單尚未建立／串接，報名按鈕需待表單連結確定後更新。時間、地點尚未公布。
